Documentation for smfGetYahooHistory() function


Description

    Returns historical stock quotes from Yahoo

Syntax

    =smfGetYahooHistory( Ticker, [Start Date], [End Date], [Period], [Items], [Headers], [Re-Sort], [Rows], [Columns] )

Parameters

    Ticker = Ticker symbol (e.g "AAPL")
    Start Date= An optional starting date. The date can either be a string value (e.g. "mm/dd/yyyy") or an EXCEL serial date value. If none is specifed, the default is "01/01/2000".
    End Date= An optional ending date. The date can either be a string value (e.g. "mm/dd/yyyy") or an EXCEL serial date value. If none is specifed, the default is tomorrow's date.
    Period= An optional character indicating the data period to retrieve. The default value is "d". Possible values:

    "d" = Daily quotes
    "w" = Weekly quotes
    "m" = Monthly quotes
    "q" = Quarterly quotes
     Items = An optional character string indicating which data items to retrieve. The default value is "DOHLCAV". Possible values:

    "T" = Ticker symbol
    "D" = Ending date of the period
    "O" = Opening price of the period
    "H" = High price for the period
    "L" = Low price for the period
    "C" = Unadjusted closing price for the period
    "A" = Adjusted closing price for the period
    "V" = Trading volume for the period
    Headers = An optional value to indicate whether column heading(s) should be displayed in the first row. Default is 1. Possible values:

    0 = No column headings
    1 = Display column headings
     Re-Sort = An optional value to indicate whether data should be re-sorted or not. Default is 1. Possible Values:

    0 = Do not re-sort data; display data as returned from Yahoo!; earliest data will be at the top of the table.
    1 = Reverse the order of data; latest data will be at the top of the table.
     Rows = An optional integer value that can override the number of rows of desired output. This is typically not used, as it is automatically based on the number of rows array-entered for the formula.
     Columns = An optional interger that can override the number of columns of desired output. This is typically not used, as it is automatically based on the number of columns array-entered for the formula.

Examples
  • This would return the seven default data items for ticker symbol AAPL:

        =smfGetYahooHistory("AAPL")

    If you array-entered the above formula over a 10-row by 7-column range, you would get the DOHLCAV data items, with headings, for the latest 9 days of history.

  • This would return a single item (no headings) -- the unadjusted closing price for ticker symbol AAPL for January 3rd, 2024:

        =smfGetYahooHistory("AAPL", "1/3/2024", "1/3/2024",,"c",0)

  • If cell B4 contains a valid stock symbol, i.e. "CMG", and you array-entered this formula over a 10-row by 6-column range, you would get the DOHLCA data items for the latest 9 days of history.

        =smfGetYahooHistory(B4,"1/1/2024","2/28/2025","d")


Usage notes
  • This function will need to be an array-entered formula. To array-enter a formula in EXCEL, first highlight the range of cells where you would like the returned data to appear -- the number of rows for the range should be the number of periods of data you are requesting from the function, while the number of columns for the range should be the number of data items you are requesting for each date from the function. Next, enter your formula and then press Ctrl-Shift-Enter.

  • If the function is array-entered over a range that is larger than the amount of data available from Yahoo, the excess portion of the range will be blank.

  • If the function is array-entered over a range that is smaller than the amount of data returned from Yahoo, the excess Yahoo data will not be displayed.

  • Option price history can also be retrieved using the option symbol, for example "CMG251219C00045000". The function will return daily pricing for up to 4 weeks.

  • History for dividends and stock splits are not available at this time. You can retrieve this info from Yahoo's "Historical Data" page for the particular stock.
