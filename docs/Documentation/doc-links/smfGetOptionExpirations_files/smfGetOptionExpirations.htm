Documentation for smfGetOptionExpirations() function


Description

                Returns all option expiration dates available for a specific equity.

Syntax

                =smfGetOptionExpirations( Ticker, [Source], [Put/Call], [Strike Price], [Rows], [Columns], [Get Type], [Interval])


Parameters
  
   
Ticker

 = Ticker symbol of underlying equity (e.g "MMM" or "SPY").
    
Source = Optional parameter to indicate which data source the expiration dates should be retrieved from. Only Yahoo is now valid.
Defaults to "Y" for Yahoo
   
Put/Call = Optional parameter that will allow you to create option ticker symbols for the smfGetOptionQuotes() function. If desired, both the Put/Call and Strike Price parameters should be  passed. This parameter would be a literal value of "Put" or "Call" to indicate the type of ticker symbols that are desired. Can be abbreviated to "P" or "C".
     
Strike Price = Optional numeric value that can allow you to create option ticker symbols for the smfGetOptionQuotes() function. If desired, both the Put/Call and Strike Price parameters should be passed.
   
Rows and Columns = These are advanced optional parameters to override the size of the returned array of data. For internal use only.
    
Get Type = Optional value to determine the type of Internet request to make. Defaults to 4. For now, other values are experimental:

0 = XMLHTTP "Get" Request 
1 = IE Object Request
2 = HTMLDocument Request
3 = XMLHTTP "Post" Request
4 = WinHttpRequest.5.1 "Get" Request (for Yahoo urls that require a "crumb" value)


Interval          = Optional value to specify the type of expiration date to retrieve. Defaults to "A".

 A = All expiration dates.
W = Weekly expiration dates.
M = Monthly expiration dates.


Examples


  • =smfGetOptionExpirations("AAPL", , , , , , , "M")

    • ... would return the monthly option expiration dates for "AAPL" from Yahoo Finance:
Friday, March 20, 2026
Friday, April 17, 2026
Friday, May 15, 2026
Thursday, June 18, 2026
Friday, July 17, 2026
Friday, August 21, 2026


  • smfGetOptionExpirations("MMM","Y","C",100)
            ...would return the available option expiration dates for "MMM" from Yahoo, formatted as $100 call ticker symbols ready for the smfGetOptionQuotes() function:

MMM 6/23 2023 $100.00 Call
MMM 6/30 2023 $100.00 Call
MMM 7/7 2023 $100.00 Call
MMM 7/14 2023 $100.00 Call
MMM 7/21 2023 $100.00 Call
MMM 7/28 2023 $100.00 Call
MMM 8/18 2023 $100.00 Call
MMM 9/15 2023 $100.00 Call


Usage notes
  • As of January, 2026,  some stock options now have Mon, Wed, and Fri weekly expiration dates (AMZN, AAPL, META, etc.) 
  • The function will return a Thursday expiration date if the normal Friday date is a market holiday; i.e. Good Friday, Juneteenth.

  • In almost all cases, this will need to be an array-entered formula. For this function, this will be a multi-row by one column array. To array-enter the formula in EXCEL, first highlight the range of cells in a column where you would like the returned data to appear -- the number of rows for the range should be AT LEAST the number of expiration dates you are requesting. Next, enter the formula in the formula bar and then press Ctrl-Shift-Enter.
